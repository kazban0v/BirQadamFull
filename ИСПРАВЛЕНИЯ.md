## 🔧 Как проверить исправления:

### 1. Проверка обновления TF после оценки фото:

1. Откройте браузер с DevTools (F12) → Network
2. Оцените фото на 2 звезды
3. Проверьте ответ API `/custom-admin/api/v1/photo-reports/<id>/rate/`
4. В ответе должны быть:
   ```json
   {
     "photo": {
       "trust_factor": <новое_значение>,
       "average_rating": <новое_значение>
     }
   }
   ```

### 2. Проверка обновления TF после выхода из проекта:

1. Выйдите из проекта (укажите причину)
2. Проверьте ответ API `/custom-admin/api/v1/projects/<id>/leave/`
3. В ответе должно быть:
   ```json
   {
     "trust_factor": <новое_значение>,
     "penalty_applied": true
   }
   ```

### 3. Проверка истории TF:

1. Откройте профиль волонтера
2. Нажмите "История изменений TF"
3. Должна открыться модалка с историей без ошибок
