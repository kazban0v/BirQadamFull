# Создание тестовой истории рейтинга

## Описание

Команда `create_rating_history` создает тестовые данные для графика "Динамика рейтинга" в аналитике организатора.

## Использование

```bash
python manage.py create_rating_history --username <username> [опции]
```

## Параметры

- `--username` (обязательный) - Username организатора
- `--days` (по умолчанию: 30) - Количество дней для создания данных
- `--min-per-day` (по умолчанию: 1) - Минимальное количество активностей в день
- `--max-per-day` (по умолчанию: 5) - Максимальное количество активностей в день
- `--clear` - Удалить старые тестовые активности перед созданием новых

## Примеры

### Создать историю на 30 дней с 1-5 активностями в день:
```bash
python manage.py create_rating_history --username 78454161451
```

### Создать историю на 60 дней с 2-8 активностями в день:
```bash
python manage.py create_rating_history --username 78454161451 --days 60 --min-per-day 2 --max-per-day 8
```

### Очистить старые данные и создать новые:
```bash
python manage.py create_rating_history --username 78454161451 --clear
```

## Как это работает

1. Команда создает `Activity` объекты для организатора за указанный период
2. Каждая активность влияет на рейтинг (согласно логике в `stats.py`)
3. Рейтинг рассчитывается как: `базовый_рейтинг (5.0) + (количество_активностей * 0.1)`
4. Максимальный рейтинг ограничен 50.0 для более реалистичной визуализации

## Типы активностей

Команда создает следующие типы активностей:
- `task_assigned` - Назначена новая задача
- `task_completed` - Задача выполнена
- `photo_uploaded` - Загружено фото
- `project_joined` - Новый волонтер присоединился

## Проверка результата

После выполнения команды:
1. Откройте страницу аналитики организатора: `/portal/organizer/analytics`
2. Проверьте график "Динамика рейтинга"
3. Данные должны отображаться в виде плавной линии с градиентом

## Примечания

- У организатора должны быть созданы проекты перед запуском команды
- Команда использует существующие проекты организатора для привязки активностей
- Рейтинг автоматически обновляется после создания активностей
