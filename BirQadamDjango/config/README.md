# Config Directory

Эта папка содержит конфигурационные файлы проекта, включая секретные данные.

## Важно! ⚠️

**НЕ КОММИТЬТЕ** файлы с секретами в git!

## Файлы

- `firebase-service-account.json` - Учетные данные Firebase для push-уведомлений

## Использование

Файлы из этой папки используются в:
- `birqadam_project/settings.py` - настройки Firebase
- `admin_panel/services/fcm_modern.py` - отправка push-уведомлений

## Безопасность

Убедитесь, что файл `.gitignore` в этой папке настроен правильно, чтобы секретные файлы не попали в репозиторий.
